# IMDb 单集库接入与设置

## 目标

沿用当前分支及既有改动，正式保留本地 IMDb 全量单集索引，补足 TMDB 缺失的 IMDb 外链；设置页支持手动更新、仅手动/每天/每周检查及本机状态，复用 ui-* 与任务中心。更新失败保留旧索引；不自动关联入库，不改 IMDb 主键约定。

## 状态

实现与验收完成。已恢复 Flask 调试服务 127.0.0.1:5000；本机完整单集库已建立，设置默认每周更新。本轮补丁单独提交在当前分支，保留原有未提交工作，不推送或合并。

## 决定

- 索引保存在 DATA_DIR/imdb/episodes.sqlite3，不进入云快照；不长期保留完整 TSV/gzip。
- 四整数列、复合主键、WITHOUT ROWID；编号不唯一时不自动使用。库内现有关系 > TMDB 外链 > IMDb 单集表。
- 临时下载和临时建库，完整校验后原子替换；读取和发布使用短锁，建立索引时旧版本仍可查询。
- 默认每周条件检查，MovieDB 运行时定时执行；停机后下次启动补查，设置修改立即生效。没有索引时首次初始化。
- 整剧 ID 未知、文件集号缺失和预告片仍保留待核对。

## 验收

- 小样本测试条件更新、坏数据/网络失败保留旧库、去重/并发、调度配置、只读/远程/CSRF 限制及回退优先级。
- 完整测试、JS 语法与规则检查；浏览实际设置页，执行手动更新并验证状态与样式。
- 实际本地库约 1002 万条，索引已就绪后重识别；先前 137 个受缺映射阻塞的视频可取得 IMDb 单集 ID，另列仍需核对的项目。
- 仅提交本轮补丁，保留其它未提交工作；不推送或合并主分支。
