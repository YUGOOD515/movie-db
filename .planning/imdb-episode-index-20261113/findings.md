# 实现要点

单集主键继续使用 IMDb ID，TMDB 仍负责标题、季集结构和展示资料。只有 TMDB 目录内仍缺编号、IMDb 官方表恰有一个候选且不与其它位置冲突时才回退；现有本机关系和 TMDB 外链优先。

完整编号索引不进入媒体库或云快照，而保存在 DATA_DIR/imdb/episodes.sqlite3。临时下载、建库、完整性检查和异常数据量检查均完成后原子替换，旧版本在构建期间仍可查询。ETag 相同只记录检查时间，新版本发布才触发重新扫描和识别缓存失效。

默认每周检查；每天与仅手动在设置立即生效。调度在 MovieDB 进程运行时执行，启动后补查逾期任务，失败退避一小时。手动和定时共用单飞任务，后台任务面板可看进度及失败重试。多进程部署需要单一更新进程，与当前桌面应用的单进程约定一致。

证据见本机 verification.json 和 discovery-after.json。编号补齐不等于身份全部确认：SKAM 分片和预告片、缺整剧编号、规则低置信度仍需人工核对。
