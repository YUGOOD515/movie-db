# 媒体图片选择

## 目标

允许用户在媒体资源管理页为每部电影或剧集分别设置横板海报、竖版海报和 Logo，并在管理页同时清晰展示三类当前图片。

## 阶段

- [complete] 1. 审计图片表、管理页查询、卡片模板与现有样式
- [complete] 2. 实现 Model 图片候选查询与首选图片切换
- [complete] 3. 实现 Flask 路由、参数验证与重定向
- [complete] 4. 重排媒体资源管理卡片，Logo 叠加横板且两类海报等高
- [complete] 5. 添加测试并完成数据库、模板与回归验证

## 决策

- 不新增数据库字段；每种图片类型中 `image_position = 1` 继续作为全站首选图片。
- 切换时在同一媒体、同一图片类型内交换位置，避免唯一约束冲突并保持候选顺序。
- 前端优先使用 Bootstrap 网格、卡片、按钮和表单，仅保留必要的媒体画幅 CSS。
- 不修改任务开始前已有的 `.gitignore` 用户改动。

## 错误记录

- 重排后旧测试仍查找独立的 `>Logo<` 标题而失败；功能输出正常，已将断言改为新的“Logo 叠加预览”语义。
