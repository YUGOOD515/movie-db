# Details 筛选控件与主题统一

## 目标

审视详情、首页最近观看、类别筛选和媒体资源管理页面，统一 details 页面中的年份、评分、制作国家选择框及播放按钮，保持“全部”类按钮尺寸不变，并将相关蓝色主题改为白色。

## 阶段

- [x] 1. 定位目标页面及跨页面共用样式
- [x] 2. 局部修改模板和 CSS
- [x] 3. 更新测试并完成代码检查

## 边界

- 优先复用类别筛选页的 Bootstrap 组件与现有 CSS。
- 不调整“全部选择”类型按钮的尺寸。
- 不改业务、数据库和播放逻辑。
- 不进行浏览器视觉检查。

## 错误记录

- 首次合并补丁因 `.episode-selected-badge` 上下文位置与预期不一致而未应用；改为分段补丁并使用已确认的准确上下文。
- 完整测试发现既有断言仍期待旧文案 `Season 1 · Episode 2`，而当前模板实际已使用 `S1 · E2`；更新断言以匹配当前页面，不改变页面文案。
- 最终行号检索中，正则以 `--` 开头被 `rg` 误识别为参数；改用 `rg --` 终止参数解析。
