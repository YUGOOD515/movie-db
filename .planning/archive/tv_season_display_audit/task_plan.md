# 剧集季数据显示核查

## 目标

核对真实数据库与详情页数据链路，确定“小谢尔顿只显示第三季”的影响范围和根因，修复代码并完成回归验证，不修改数据库结构。

## 阶段

- [completed] 1. 核对数据库中小谢尔顿及全部剧集的季、集、来源分布
- [completed] 2. 追踪 models、app 与模板中的季筛选链路
- [completed] 3. 实施最小范围修复并补充回归测试
- [completed] 4. 验证真实页面数据、电影详情及完整测试

## 边界

- 优先修复查询或展示逻辑。
- 若真实数据库本身缺数据或需要数据写入，先提交可审核方案，不直接写库。
- 保留现有当前单集、多版本播放、观看进度与图片逻辑。

## 错误记录

- 数据库首轮统计使用了不存在的 `tv_series.name`，SQLite 返回 `no such column`；后续改用表结构确认后的 `series_name`。
- 首次用 PowerShell `python -c` 核对真实渲染时引号嵌套导致字符串终止错误；改用标准输入传入只读检查脚本。
- 最终定位行号时 `rg` 正则在 PowerShell 转义后变成未闭合分组；差异检查本身已通过，定位改用固定字符串搜索。
