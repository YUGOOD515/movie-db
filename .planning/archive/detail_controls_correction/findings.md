# Findings

- 用户要求播放和收藏同排；因两个按钮均为 2/3 无法同排，结合上一轮收藏为播放按钮约 1/3 的要求，按播放 2/3、收藏 1/3 实现。
- 季选择器仅需收紧尺寸；季摘要恢复年份、集数、评分的普通横向排列。
- IMDb 从 Hero 右侧独立对齐改为与简介正文左边线一致。
- 既有详情页约定要求保留 Jinja `play_control` 宏和本地 JavaScript 单集切换逻辑，本轮只做模板结构与 CSS 局部调整。
- 当前播放控件和收藏表单是相邻块级元素；可增加 `detail-action-row` 统一承载，并让播放容器 flex: 2、收藏 flex: 1。
- 当前季按钮由 11rem × 4rem 和 1.05rem 字号造成偏大；季摘要面板显式使用纵向 flex，IMDb 也显式 `justify-content-end`，均可局部撤销。
