# 首页卡片栅格比例

## 目标

让首页最近观看、收藏夹、最近添加分别严格占桌面 12 栏栅格的 6、3、2 栏，并与正文左侧对齐；保留横向滚动和末尾留白。

## 阶段

- [complete] 核对首页模板、详情页栅格基准与现有 CSS
- [complete] 用统一栅格公式替换三类卡片的独立固定宽度
- [complete] 运行静态检查与测试，记录结果

## 约束

- 不使用 design-taste-frontend skill。
- 不做视觉检查。
- 优先 Bootstrap 组件与变量，仅保留必要自定义 CSS。
- 不改动用户已有的无关修改。

## 错误记录

- 首次测试有 2 项失败：旧断言仍查找 `media-rail--folder / --poster`；实现已改为单位类，测试同步更新为 `--span-3 / --span-2 / --span-6`。
- 一次组合补丁因 hunk 边界格式错误未应用；拆分并修正补丁格式后成功应用，未影响代码内容。

## 结果

- 首页最近观看与电影类别使用 6 单位，收藏夹使用 3 单位，竖版媒体使用 2 单位。
- 所有断点都将 gutter 纳入比例计算；手机端采用可读的响应式单位尺度，保证相邻元素的占位节奏和跨板块对齐线一致。
- 12 项单元测试通过，`git diff --check` 无空白错误。
