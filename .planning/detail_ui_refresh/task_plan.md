# 详情页 UI 优化

## 目标

在不改数据库和播放后端的前提下，减轻 Hero 蒙版并下移内容，增加可切换的当前单集详情，精简 Episode 导航卡片，重新分组作品信息与当前播放文件。

## 阶段

- [completed] 1. 审计当前详情模板、样式、脚本与实际模板数据
- [completed] 2. 调整 Hero 层级、蒙版、内容位置和响应式样式
- [completed] 3. 实现当前单集详情与 Episode 卡片选择交互
- [completed] 4. 重排作品信息、媒体参数与外部链接
- [completed] 5. 补充语义测试并完成电影/剧集回归验证

## 决策

- 保留 `play_control` 宏及所有播放 URL，不让 Episode 卡片点击触发播放。
- 服务端渲染各单集详情面板，Episode 卡片只用一个 `data-*` 目标标识，由 `site.js` 切换可见面板，避免复制播放来源数据。
- Hero 简介继续读取 `media.overview`；单集简介仅进入新增的当前单集详情。
- 样式沿用 Bootstrap、现有主题变量、圆角和阴影，只新增详情页必要规则。
- 不进行视觉验收，只执行模板、DOM 语义、脚本和响应式规则检查。

## 错误记录

- 首轮回归有两条旧结构断言失败：旧标题“媒体信息”和旧卡片播放按钮；已按新需求更新断言后通过。
