# Findings

- 当前 `collection` 表通过 `movie.collection_id` 表示 TMDB 电影合集，不能复用为用户收藏。
- 电影和剧集已有独立的类别、制作国家、语言关系表，可用于统一筛选。
- 现有 `/genres` 只展示电影类别代表卡，需改为 GET 参数驱动的电影/剧集筛选页。
- 首页已有电影类别横向板块，尚无剧集类别板块。
- 完整结构文件是 `migrations/schema.sql`；最新已执行迁移是 `004_add_watch_progress.sql`。
- 收藏迁移草案为 `migrations/005_add_favorites.sql`，包含三个系统收藏夹和可容纳电影/剧集的收藏项表。
- 实际库同时包含中文与英文类别名，图标映射必须提供通用回退图标。
- 制作国家存在空代码记录，筛选选项应排除空代码；语言原生名可能为空，应回退英文名或语言代码。
- 当前数据年份范围为电影 2014–2026、剧集 2012–2026，年份选项应从库中动态生成。
- 测试电影具备剧情、美国、英语、2026、8.0 数据，可覆盖组合筛选；测试剧集可覆盖媒体类型和类别筛选。
- 真实库筛选页共展示 31 个已关联媒体，其中电影 9 个、剧集 22 个；组合条件无结果时模板正常渲染。
- 迁移执行前备份为 `backups/movie-before-favorites-20260828-162951.db`。
- 迁移后 `PRAGMA integrity_check` 为 `ok`，`PRAGMA foreign_key_check` 为空，三个系统收藏夹均存在。
- 详情页主操作区位于 `detail-primary`，收藏按钮可与播放按钮保持同一 3 单位对齐线。
- 测试数据库直接执行 `migrations/schema.sql`，因此获批迁移后必须同步完整结构文件。
- 首页收藏夹目前是静态计数且不可点击，需要改为真实查询并链接收藏页的文件夹筛选。
- 最终真实库仍有 0 个收藏项，没有为用户自动写入收藏；三个系统收藏夹计数均为 0。
- 首页、收藏、最近添加、类别、未观看和最受好评路由均返回 200，侧边栏入口均存在。
