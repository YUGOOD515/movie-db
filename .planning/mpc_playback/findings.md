# Findings

- Project responsibility split: `models.py` owns SQLite, `helpers.py` owns AList access/player launch, and `app.py` owns request orchestration.
- Current playback URLs are generated by `helpers.build_alist_url()` and rendered directly as anchors.
- `helpers.get_video_link()` and `helpers.play_video()` exist but currently have no callers.
- `templates/detail.html` has a pre-existing unrelated backdrop width modification that must be preserved.
- Homepage records expose the selected source as `source_order`; detail records expose `source_id` per source.
- The clean local route contract is `/play/<media_type>/<source_id>`: look up the stored path server-side, resolve the raw URL, launch MPC-HC, then return HTTP 204 so the current page is not replaced.
- The media-association page also contains AList jump anchors; these should become plain stored-path text while retaining AList direct-link input for imports.
- Final repository search found no `build_alist_url`, `source.alist_url`, `mapping.alist_url`, or AList-origin playback `href` references.
