# Findings

- 首页所有横向轨道使用全宽滚动容器，内部 `container-xl d-flex` 与标题共用 Bootstrap 对齐线。
- 当前 `.media-rail--wide / --folder / --poster` 通过互不相关的固定像素宽度定义卡片，不能表达严格的 6/3/2 栏比例。
- 详情页主内容使用 `container-xl` 下的 Bootstrap `.row`，主栏为 `col-md-3`，可作为同一容器栅格基准。
- 为兼容此前约 70% 的整体缩放，以 6 单位卡片的现有宽度为锚点，并将 gutter 纳入占位计算：3 单位为 6 单位占位的一半，2 单位为三分之一。
- 手机端使用一行 12/6/4 响应式跨度作为同一比例单位，分别映射到本需求的 6/3/2；从 `sm` 起恢复此前缩小后的 6 单位基准，并继续按同一 gutter 公式推导其余宽度。
