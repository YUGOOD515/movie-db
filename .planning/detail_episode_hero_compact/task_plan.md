# 当前单集 Hero 与紧凑选集优化

## 目标

在保留详情页现有视觉体系与播放后端的前提下，让剧集 Hero、播放与媒体摘要随选中单集同步更新，并把选季与单集列表压缩为清晰的紧凑结构。

## 阶段

- [x] 1. 核对模板、样式、脚本、详情数据与现有测试
- [x] 2. 重组 Hero 和季选择模板，移除大型单集详情块
- [x] 3. 实现单集选择驱动的 Hero、媒体摘要和季摘要同步
- [x] 4. 调整紧凑缩略图卡片及响应式视觉
- [x] 5. 补充测试并完成模板、脚本、页面与视觉验证

## 边界

- 保留作品名、收藏、播放来源选择、观看进度和作品信息。
- 只改详情页必要的数据准备、模板、CSS、JavaScript 与测试。
- 不修改数据库结构或真实数据，不大规模重构其他页面。
- 复用 Bootstrap、现有主题变量、圆角、阴影和容器对齐规则。

## 错误记录

- 首轮完整测试有 1 条旧结构断言失败：测试仍要求 `S01E02`、大型单集详情和横向轨道；已按新结构更新语义断言。
- 第二轮组合验证命令的最终 `rg` 模式在 PowerShell 中引号未闭合，导致整条命令未执行；拆分为不含嵌套双引号的检查命令。
- Playwright CLI 首次启动默认寻找系统 Chrome，但该路径不存在；改查 CLI 浏览器选项与本机已安装的 Playwright Chromium，不重复同一启动方式。
