# Findings

- 当前工作区已有未提交的详情页与媒体探测改动，本次在其上增量实现，不回退现有修改。
- 当前剧集 Hero 只在首屏读取服务端选出的 `featured_episode`；点击单集仅切换 Hero 下方的大型 `episode-feature`。
- 单集和来源对象已经包含实现同步所需的标题、简介、评分、日期、时长、剧照、观看进度、播放 URL 以及文件/音视频参数。
- `_build_media_facts` 已包含文件大小、帧率和基础音频信息，可复用并为每个单集来源预先生成简洁摘要。
- 现有多季展示已经恢复全部有单集的季，本次应保留该数据修复，只改成单个“选择季”入口与对应季摘要。
- Hero 当前固定使用整部作品背景、作品简介和当前季评分；剧集标题只部分读取单集数据，客户端没有 Hero 更新接口。
- `play_control` 宏在服务端生成单来源链接或多来源下拉，可为每集预渲染一份 Hero 内容面板，通过选中状态切换，避免在 JavaScript 中拼播放菜单。
- 电影详情同样复用 Hero 和文件事实，改造必须把剧集专属 DOM 包在条件内，确保电影页面行为不变。
- 真实“小谢尔顿”页面首屏显示当前第 3 季第 12 集剧照、标题、简介、18 分钟、日期、1080p、HEVC、24 fps、1.16 GiB、AAC 5.1 与单集评分；Hero 信息层级清楚，没有参数堆叠。
- 1029 px 宽视口下选集网格为四列，缩略图保持 16:9，季按钮与摘要位于同一对齐线；选集区紧接 Hero，首屏已能看到首行卡片。
- 浏览器控制台无脚本错误，只有 Edge 对懒加载图片占位的说明性信息。
- 点击第 3 季第 1 集后，Hero 的剧照、标题、简介、播放进度标签、评分、文件大小、帧率与音频均同步变化，选中徽标和 `aria-pressed` 同步更新。
- 切换到第 1 季后，季摘要更新为 2017、22 集、7.1，Hero 自动切换到该季第 1 集；季菜单收起且只保留一个入口。
- 390×844 移动视口下 Hero 改为纵向布局，标题和媒体信息仍可读，长简介正常收起为“更多”；选季按钮与摘要换行后保持对齐，没有横向溢出。
- 电影《星际穿越》详情页仍保留原有作品 Hero、播放按钮、作品信息与当前播放文件区域，剧集专属选择逻辑没有渗入电影页面。
