# Findings

- 当前剧集播放控件位于右侧 Hero 单集面板，收藏位于 Logo 下方；需要把每集播放控件预渲染到左栏并由现有单集切换逻辑同步显示。
- 当前选集为响应式 CSS Grid；需要恢复为外层可横向滚动、内层 `container-xl` 不换行的轨道，以保持与主页媒体列表一致的左右滑动方式和左对齐线。
- 当前季按钮固定显示“选择季”，右侧摘要横排且重复显示季名；应让按钮显示当前季名，并把右侧简化为年份、集数、评分的纵向统计。
- 当前来源摘要直接显示像素尺寸、带小数 fps 和音频；应用层应统一转成 4K/2K/1080P/720P、整数帧，并停止向 Hero 输出音频。
- 主页横向列表使用 `media-rail`、`media-rail-track` 和 `media-rail-item`，外层负责横向滚动、内层 `container-xl` 负责与页面内容对齐；选集可直接复用该结构，仅定义更小的卡片基准宽度。
- 为保证单集切换后左栏播放同步，新增与 Hero 内容同键的 `data-episode-hero-control` 面板；收藏表单保持唯一并位于所有播放面板之后。
- 清晰度标签应同时供剧集和电影 Hero 使用，但底部电影“当前播放文件”仍保留真实像素、帧率与音频技术详情。
- 1280×800 真实页面中，播放按钮占满左栏宽度，收藏按钮宽度约为其三分之一且为图标型圆角矩形；两者均紧接 Logo 下方。
- Hero 已显示 1080P、24帧且不再显示音频，IMDb 评分仍位于黑幕右下区域，简介保持原位置和行数逻辑。
- 季工具栏左侧只显示当前“第 3 季”，右侧以放大的 2019、较小的 21 集和放大的 6.7 纵向排列；首屏未出现旧“选集”标题。
- 1280px 桌面端实页截图确认：选集横向轨道可见约 6 张完整卡片，第 7 张部分露出；季选择器、右侧纵向年份/集数/评分和作品信息之间层级清楚。
- 选集轨道左边线与 Hero 左侧控制区保持同一容器基线，卡片文字与底部进度条在缩小卡片后仍可辨认。
- 点击 S3E1 后，Hero 背景、集数、标题、元数据、简介、IMDb 与播放按钮均同步为该集；播放和收藏仍保持 Logo 下方的长按钮/三分之一宽按钮比例。
- 季选择器实测从第 3 季切到第 1 季后，按钮文字变为“第 1 季”，右侧更新为 2017 / 22 集 / 该季评分，列表与 Hero 自动切到 S1E1。
- 390×844 移动端实页确认：播放按钮满宽，收藏为其约三分之一宽；Hero 信息可读，简介仍两行折叠并显示“更多”。季摘要与选择器并排，横向卡片保留下一张露出。
- 电影页回归确认：Logo 下方播放/收藏比例一致，Hero 简介显示 4K 且无音频摘要；作品下方“当前播放文件”仍保留完整原始技术信息，不受精简影响。
